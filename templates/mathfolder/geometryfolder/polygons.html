Правильные многоугольники

Периметр правильного многоугольника через длину его стороны

P = a n

Длина стороны правильного многоугольника через его периметр

a = P n

Количество сторон правильного многоугольника через его периметр

n = P a

Внутренний угол правильного многоугольника через сумму его углов

a ° = S n

Сумма углов правильного многоугольника через его внутренний угол

S = a ° n

Количество сторон правильного многоугольника через сумму его углов

n = S a °

Произвольные многоугольники

Количество сторон произвольного многоугольника через сумму его углов

n = S 180 ° + 2

Сумма углов произвольного многоугольника через количество его сторон

S = ( n − 2 ) 180 °
